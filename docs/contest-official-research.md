## 结论

1. `traedemos.com/zh-CN` 当前是 **TRAE DEMO WALL 作品提交与展示平台**。官网页面、提交表单文案与公开源码足以核实平台的资料要求，但不等于已核实本次中山活动的全部比赛规则。[S1][S3][S4]
2. 官网提供 `广东 → 中山` 城市归属，代码分别为 `GD`、`442000`。来源标签包括 `TRAE Friends（城市活动）`。这能证明平台有城市分类，不能据此断言“广东中山赛区”的赛事分组、赛程或选手资格。[S2][S7]
3. **尚未核实本次中山活动的开始时间、作品截止时间、活动地址、组别、评审维度/权重、奖项、作品创作工具限制、AI 图片许可要求。** 不应用历史作品日期、盲盒中的“1024”、标签自动审核窗口推算上述事项。
4. 猫咪、投票器、可爱圆角风三词均存在于官网公开盲盒词库。词库只能证明这些词属于平台的主题/功能/风格词，不能验证当前用户账号是否已经锁定了这组命题。[S8]

## 提交材料要求

以下是表单文案与公开表单校验的交集。字符限制按平台校验表述，不自行解释为中文汉字或字节。仅准备材料，没有代用户提交。[S1][S4]

| 内容 | 已核实的平台约束 |
| --- | --- |
| 项目名称 | 2–50 个字符 |
| 一句话简介 | 10–100 个字符 |
| 省份、城市、项目类别 | 必选 |
| 开发状态 | 前端表单必选；字典值为“创意构思”“初步原型”“功能完成”“已上线” |
| 作品来源 | 至少 1 个、至多 5 个标签，应按真实来源选择 |
| 封面 | 必须有 1 张；页面文案“支持 SVG, PNG, JPG 或 GIF (最大 5MB)” |
| 项目截图 | 1–5 张；页面文案“支持 PNG, JPG，每张最大 5MB” |
| 创作故事 | 前端 20–2000 个字符；后端另按去除 HTML 后的纯文本校验至少 20 个字符 |
| 核心亮点 | 1–5 条，每条非空且不超过 30 个字符 |
| 使用场景 | 至少 1 条，每条非空且不超过 100 个字符 |
| 团队成员 | 至少 1 人，每名不超过 20 个字符 |
| 团队介绍 | 必填，不超过 500 个字符 |
| 联系电话、联系邮箱 | 可空；若填邮箱应为有效邮箱 |
| Demo 链接 | 填入时须为有效 URL；公开前后端校验都允许空字符串，**不能声称平台强制必填** |
| 代码仓库 | 页面标明选填；填入时须为有效 URL |

开发状态字典来自 [S9]。文件前端大小检查为 `5 * 1024 * 1024` 字节，封面和截图均有检查；上传控件的 `accept="image/*"` 比可见说明更宽，稳妥交付应按可见说明准备封面 PNG/JPG、截图 PNG/JPG，每张小于 5MB。[S10]

源码提交步骤为：基础信息 → 视觉素材 → 内容说明与链接 → 团队。文件上传和最终提交都属于写入操作，本次未执行。[S11]

注意：同一省份字典还单列“Trae创造力大赛”，值为 `TRAECC`，其子项是“线下活动”，值为 `OFFLINE`。**不能把 `广东/中山`、`TRAE Friends（城市活动）`、`Trae创造力大赛/线下活动` 当成完全等价的比赛组别。** 用户参加哪一项应由本次活动通知或组织者确认。[S2]

查询 `country=GD&city=442000` 的作品接口本次返回 `total: 44`。列表包含多件 2026-04-11 的历史作品和一件 2026-10-08 的作品。这些是平台记录的作品提交时间，不是本次 2026-10-24 活动的开始或截止时间。[S12]

### 不得误读的日期

来源标签 `TRAE Friends（城市活动）` API 返回：

```json
{
  "isAutoAudit": true,
  "auditStartTime": "2026-05-15T12:48:00.000Z",
  "auditEndTime": "2026-12-31T12:48:00.000Z"
}
```

字段在提交接口中用于决定标签是否触发自动审核。**这不是中山比赛的报名、创作或提交起止时间。** 不应在交付材料中称其为赛事截止时间。[S6][S7]

## 本次 Demo 的提交准备缺口

此节是依据已核实的平台材料要求整理的交付清单，不是新增官方比赛条款。

- 需要作者本人确认省份、城市、来源标签、开发状态及真实团队信息；不虚构姓名、电话、邮箱。
- 需要准备封面 PNG/JPG 和 1–5 张真实界面截图，每张小于 5MB。实际 UI 截图比纯插画更适合作为“项目截图”。
- 需要准备 10–100 字符简介、20–2000 字符故事、1–5 条短亮点、至少 1 条场景、团队介绍。
- 建议提供可从他人设备打开的公开 HTTPS Demo 链接。平台校验允许链接空白，但本地 `127.0.0.1` 地址不能供外部评委实际体验；不应将其作为公开可用交付。
- 若当前仅用 localStorage，应如实称为本地演示版，不宣称多人同步、防刷票或生产级投票；模拟初始票数也应继续标注为演示数据。这是防止作品描述与实际行为不符的工程建议，不是核实到的比赛强制项。
- 是否要求必须由 TRAE 完成、是否限制其他 AI 编码工具、是否允许外部生成图片、是否需要过程截图/录屏/代码仓库/讲解视频，均尚未核实。不要声称已经满足。
